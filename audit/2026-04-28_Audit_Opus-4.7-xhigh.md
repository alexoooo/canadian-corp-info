# Documentation Audit

**Date**: 2026-04-28  
**Scope**: All 10 top-level Markdown files in this repo. Findings are scoped to topics the existing pages already cover; net-new topics outside the current pages are listed briefly at the end but not enumerated as findings.  
**Method**: Each file was read in full. Phase-1 exploration findings were verified against the source files and primary references (CRA, Department of Finance, ITA) before being included; several agent-reported findings did not survive that verification and were dropped.

## Severity legend

- **CRITICAL** — factual error in tax/bookkeeping rules, or load-bearing instruction that will mislead a CCPC owner.
- **HIGH** — material clarity or consistency defect, or an in-scope concept the page promises to cover but doesn't.
- **MEDIUM** — improves accuracy or readability but not load-bearing.
- **LOW** — spelling, hyphenation, comma splices, single-word style.

## Repo-wide findings

### [HIGH] DRIP date convention is undefined

`Adjusted-Cost-Base.md:41`, `Adjusted-Cost-Base-Tracking.md:174`. ACB.md says DRIP is treated as if you received the cash and reinvested it; Tracking.md says DRIP is entered as a Buy with `Commission = 0`. Neither file specifies which date to use (declaration, ex-distribution, or payment/reinvestment). For corporate accounting and FX conversion (where the Tracking doc says Buys use trade-date FX), this matters. Pick one — the reinvestment/payment date is the defensible choice — and state it in both files.

### [MEDIUM] Bank of Canada FX rate convention is unspecified

`Adjusted-Cost-Base.md:97`, `Adjusted-Cost-Base-Tracking.md:111`. Both refer to "the Bank of Canada daily exchange rate" without specifying *which* daily rate. The published rate is the indicative midpoint at 16:30 ET; the older noon-rate convention is no longer published. State this once (probably in ACB.md) and let Tracking.md reference it.

### [LOW] Schedule abbreviation drift

`T3.md` mixes "Schedule 3" / "S3", "Schedule 6", "Schedule 7" / "S7", "Schedule 21" / "S21". `T5008.md` uses "S6" in headings and "Schedule 6" in body. Pick one form (suggested: spell out on first use within a section, then abbreviate) and apply repo-wide.

## Capital-Dividend-Account.md

### Factual

- **[MEDIUM]** Line 39 "For Canadian residents: do not issue a T5 information slip for this amount". Capital dividends paid to Canadian-resident shareholders are not reported on T5 — they're not income for the recipient. This is correct. Either name the typical lag or describe what the user actually does (request Schedule 89 verification before electing).
